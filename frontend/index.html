How the WQI Works

Weighted Arithmetic Water Quality Index (WAWQI) based on BIS IS 10500:2012

1

Measure Parameters

Test pH, TDS, EC, hardness, calcium, magnesium, chloride, sulphate, nitrate, and fluoride.

2

Calculate Sub-indices

Each parameter gets a quality index (qi). For pH: qi = (|val−7|/1.5)×100. For others: qi = (val/limit)×100.

3

Compute WQI Grade

WQI = Σ(normalized weight × qi). Assign grade A–E and potability status per BIS thresholds.
